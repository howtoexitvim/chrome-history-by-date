# Changelog

## 1.1 — 2026-10-06

First public packaged release of Chrome History by Date.

- Browse history newest first with date headings, search and visit counts.
- View recently closed tabs and tabs from other signed-in devices.
- Open pages in a new tab, including background opening with modifier or middle clicks.
- Prevent stale browser API callbacks from replacing the selected view or search results.
- Include MIT and Apache 2.0 licenses with the downloadable extension.

Requires Chrome 104 or later. Install by extracting the release ZIP and using
Chrome's **Load unpacked** option. No Chrome Web Store listing is available.
